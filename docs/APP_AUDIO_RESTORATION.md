# beta.3 应用音量自动恢复

日期：2026-10-05。成功启用后按 bundle ID 保存启用选择、音量及静音；重启 VolumeControl、目标应用重启或输出设备变化后自动尝试恢复。恢复仍须验证真实捕获、输出回调和原始播放静音行为，未验证时滑块不可用。

## 行为与实现

- 后台每 2 秒检测音频输出活动，面板关闭仍运行。未播放显示等待，不启动静音 tap；检测到播放后串行恢复已记住应用，失败至少间隔 30 秒重试。
- 退出使用 `suspendAll` 释放会话、保留启用选择。单应用停止、取消启用和全局停止会关闭对应自动恢复，保留音量/静音；全局停止也清除当前未运行应用的启用选择。
- `AppAudioPreferences.isEnabled` 缺省为 false，兼容旧 JSON；旧版保存音量不等于启用授权，因此升级后需成功启用一次。只有捕获验证和持久化成功才标记可调节。
- 恢复受最多 8 个应用、真实设备单流、1–2 通道 Float32 的现有限制约束；与 BlackHole 路由测试互斥。设备/辅助进程变化先关闭旧会话，再重新验证。
- 普通测试使用内存偏好、时钟和协议替身，不修改真实设备或用户偏好。显式 `--verify-remembered-audio` 真机入口用独立内存选择，重复创建两个模型；不写用户设置、不保存声音。

## 更新、关闭与回滚

先退出旧实例，再替换并从“应用程序”中的最终路径打开 `.app`，避免移动后继续运行旧路径实例。本地包仍为 ad-hoc 签名；若 macOS 要求系统音频录制权限，按系统提示允许。升级后成功启用一次，以后无需重复点击。想关闭自动恢复，点击该行停止图标或全局停止；退出应用保留选择。

卸载时停止应用控制后退出并删除应用；系统设置可撤销权限。回滚前停止并退出，再换回 beta.2 包；新增字段不会改变旧版本的音量/静音解码，旧版不自动恢复。此功能不安装驱动、不改变默认输出、不修改系统主音量。

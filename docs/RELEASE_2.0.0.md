# VolumeControl 2.0.0

本版本汇总当前应用音量、设备选择、自动恢复和外观改进，作为 GitHub 正式 Release 发布（非 prerelease）。安装包为 Apple Silicon / Intel 通用应用。

## 用户变化

- macOS 状态栏控制系统音量、静音和输出设备；耳机接入自动切换可配置。
- macOS 14.2+ 使用原生 Process Tap 控制应用独立音量和静音，无需额外驱动。逐应用验证成功后才开放控制。
- 记住启用选择、音量与静音，重启、播放和设备变化后重新验证恢复。
- 仅显示有音频输出或已记住的应用，支持搜索与筛选。
- 改进设置窗口和面板布局，支持主题、强调色、紧凑布局、磨砂与液态玻璃；原生液态玻璃需要 macOS 26+，旧系统回退磨砂。

## 安装、更新、卸载与回滚

1. 下载 `VolumeControl-2.0.0-universal.dmg`，打开后将 `VolumeControl.app` 拖到 Applications；也可解压 ZIP 后移动应用。
2. 更新前先退出旧版本，再替换应用。已有设置保留，首次应用音量捕获按系统提示授予系统音频录制权限。
3. **本次安装包仅有 ad-hoc 签名，未经过 Developer ID 签名或苹果公证。** 首次打开可能被 Gatekeeper 阻止，确认下载来源后在“系统设置 → 隐私与安全性”允许打开。组织安全策略可能禁止运行。
4. 卸载前停止应用音量控制并退出，删除应用；可在系统设置撤销音频录制权限。
5. 回滚前停止控制并退出，用旧版本替换应用。若曾使用高级 BlackHole 路由测试，确认默认输出恢复真实设备。本版本不安装系统扩展或驱动。

## 验证与兼容性

- `swift test`：153 项，126 通过、27 项既有硬件测试跳过、0 失败（Apple Silicon）。
- Release 双架构编译，检查应用版本、签名、DMG/ZIP 内容及 SHA-256 校验。
- macOS 14+ 提供系统功能；应用独立音量需要 macOS 14.2+，最多 8 个应用。
- 应用音量只支持真实默认输出设备的单输出流、1–2 通道原生 Float32 PCM；不支持配置显示具体原因。
- 既有 HyperX USB 两进程及腾讯会议验收记录见 README。本轮不将编译成功等同于 Intel 或新机器真机验收。
- 浏览器/会议应用全覆盖、蓝牙/睡眠/长时间性能、Intel 真机和新机器安装验收尚未完成；Developer ID 签名与公证仍为 P5 后续工作。

下载后可用 `shasum -a 256 -c SHA256SUMS.txt` 验证两个安装包（将校验文件与两个安装包放在同一目录）。

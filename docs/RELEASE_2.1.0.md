# VolumeControl 2.1.0

本版本发布 macOS 原生 UI/UX 精修。安装包为 Apple Silicon / Intel 通用应用，包含 DMG、ZIP 与 SHA-256 校验文件。音频引擎、权限门槛和自动恢复业务规则未修改。

## 用户变化

- 主面板收窄至 430pt，以分区、分隔线和轻量应用行取代永久玻璃卡片，少量应用时自动收缩，多应用继续滚动。
- 简化顶部品牌信息；保留原生系统音量、静音、设备选择、应用搜索、筛选和状态。
- 正常应用不再重复显示“已启用”；停止控制在悬停或焦点时显示，低频操作可通过系统右键菜单和旁白动作访问。
- 设置采用 macOS 侧栏，分为通用、外观、音频、高级、关于，保留登录启动、耳机切换、权限入口和 BlackHole 高级路由。
- 新增系统强调色。背景材质自动随系统适配，普通设置隐藏旧玻璃风格与透明度参数；旧存储键、字段与已有颜色选择保留，不进行破坏性迁移。
- macOS 26+ 采用原生 Liquid Glass，旧系统回退到系统材质；改善深色对比，尊重减少动态效果和减少透明度。
- 菜单栏图标随现有系统音量状态变化，并保持模板图像；保留 ⌘, 设置快捷键。

## 安装、更新、卸载与回滚

1. 下载 `VolumeControl-2.1.0-universal.dmg`，打开后将应用拖至 Applications；或解压同版本 ZIP 并移动应用。
2. 更新前退出旧版本，再替换应用。既有设置保留；应用音量首次启用仍需按系统提示授予音频录制权限。
3. 本版本仍为 **ad-hoc 签名，未经过 Developer ID 签名或苹果公证**。确认来源后，若 Gatekeeper 阻止，可在系统设置的隐私与安全性页面按系统提示允许打开。组织策略可能不允许此类应用。
4. 卸载前停止应用音量控制并退出，删除应用；可在系统设置撤销音频录制权限。本次更新不安装驱动或系统扩展。
5. 回滚前停止控制并退出，再替换为 2.0.0。若运行 BlackHole 高级路由，先停止路由并确认默认输出恢复到真实设备。

## 验证与已知限制

- 本地 `swift test`：156 项，26 项既有硬件或显式验收入口跳过，0 失败。
- 双架构 Release 构建、严格 ad-hoc 签名、DMG/ZIP 内容和 SHA-256 校验验证后发布。
- 最低 macOS 14；原生应用音量仍为 **Beta**，要求 macOS 14.2+，逐应用验证成功后才启用，最多同时 8 个应用。
- 应用音量支持真实默认输出设备的单输出流、1–2 通道原生 Float32 PCM；不支持配置显示原因，不伪装为可调节。
- 原生 UI 真窗口记录来自 macOS 27.0.1；macOS 14–25 / Intel 真机、完整 VoiceOver/物理键盘与长期性能验收仍待扩大。本机 AX 未暴露测试窗口，不把跳过的验收视为通过。
- 浏览器、会议应用、蓝牙设备、睡眠唤醒和新机器覆盖仍受此前验收范围限制，见 README 和音频验证记录。
- 既有音频代码及 Xcode 27 Intel 架构诊断仍存在；两个发布二进制切片的最低系统版本保持 14.0。

将 `SHA256SUMS.txt` 与 DMG、ZIP 放在同一目录，执行 `shasum -a 256 -c SHA256SUMS.txt` 可验证下载。

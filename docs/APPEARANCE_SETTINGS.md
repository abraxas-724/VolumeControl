# 外观与实用设置

日期：2026-10-06。

## 使用

点击面板齿轮打开设置。修改即时应用，并在下次启动时保留，无需重启。

“外观与动效”页：

- 颜色模式：跟随系统、浅色、深色；设置窗口标题栏同步切换。
- 界面材质：经典、磨砂玻璃、液态玻璃。
- 强调色：靛蓝、海蓝、青色、薄荷、暖橙、樱粉。
- 动效：关闭、轻柔、灵动。轻柔提供淡入、数字过渡；灵动使用弹簧切换、按压回弹、悬停放大与静音图标反馈。筛选控件使用匹配几何滑动，无持续循环动画。
- 密度：舒适保留 320 点列表，紧凑使用 260 点列表及更小行间距。
- 顶部有可操作预览，只改变预览音量，不访问音频服务。页面可以滚动，底部重置始终可见。

“通用”页：

- 登录时启动，保留系统注册、审批和错误反馈。
- 显示音量百分比，同时控制系统与应用行。
- 显示操作提示；权限/能力错误仍会保留。
- 显示高级路由入口；即使用户隐藏入口，正在运行或启动的测试仍显示，以便停止。
- 打开面板时默认显示已启用应用，包括验证中与等待恢复的已记住应用。更改筛选不启停音频。
- 系统隐私设置入口与正常退出按钮。退出沿用既有音频会话清理流程。
- 重置界面设置只重置上述界面偏好，不修改登录注册、音频授权、已记住应用或实际音量。

## 材质与动效边界

原生 `glassEffect`、`GlassEffectContainer` 使用 macOS 26+ 可用性保护，工程最低版本仍为 macOS 14。较早系统选择液态玻璃时使用系统磨砂材质，并显示兼容说明；不声称该回退等同于原生 Liquid Glass。

玻璃用于交互按钮、切换控件，应用正文和音量卡片使用稳定的内容材质；同组玻璃控件由容器统一合成。背景是静态强调色渐变，不使用持续粒子或流动背景。设计依据 [Apple 自定义 Liquid Glass 指南](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views)，API 的系统版本以本地 Xcode SDK 声明复核。

系统“减少透明度”优先使用实色界面，系统“减少动态效果”优先关闭自定义动画、缩放与图标反馈。使用真实只读 SwiftUI 无障碍环境；测试不改变用户系统偏好。

## 实现

`InterfaceOptions` 和存储协议负责选项及回退规则；`InterfacePreferences` 通过注入仓储持久化。View 不直接访问 UserDefaults。生产仓储沿用旧 `showPercentage` 键以保留升级选择，未知枚举回退到默认值；加载不会写入默认值。

面板和设置窗口共享同一个偏好模型。设置窗口保持单实例，订阅主题更新并同步 AppKit 外观；订阅随控制器释放。界面重置与音频偏好仓储分离。退出、隐私入口和登录注册各自通过回调或协议注入，预览没有音频服务。

## 验证

- `swift test`：123 项，23 项既有硬件 PoC 跳过，0 失败。
- 新增 4 项偏好测试：加载不写入、选项重载、仅重置界面、无变化不重复写入、旧系统玻璃回退、减少透明度/动效策略。
- 扩展窗口测试：首次打开、重复打开、关闭后重新打开及浅色/深色/跟随系统标题栏切换。
- 扩展面板测试：大小提议不拉伸、紧凑布局更小、改变外观及筛选不会写系统音量或设备状态。
- 使用内存偏好、音频替身、登录项替身，检查浅色、深色液态玻璃、紧凑及通用页截图；原生玻璃已在 macOS 27.0.1 的屏幕合成窗口截图中检查。
- 普通 NSHostingView 缓存不能完整保存原生玻璃合成层。需要原生窗口截图时，显式添加 `VOLUMECONTROL_NATIVE_SCREENSHOT=1`；它仅截图测试窗口，要求屏幕录制权限，不是普通测试依赖。
- Release 构建、ad-hoc 签名、`git diff --check` 通过。

截图与临时产物保存在被忽略的 `.build/`。没有切换实际音频设备、调节真实系统音量或修改登录项来做测试。真实状态栏自动点击和 VoiceOver 仍受当前辅助功能权限限制；macOS 14 上的视觉回退与长时间 GPU/CPU 性能仍需对应环境验收，未宣称实测完成。

本轮不改变 Process Tap 能力范围，也未修复之前报告的设备名称读取竞态。新界面无需新音频权限、驱动或系统扩展；替换应用仍沿用 README 的正常退出、安装及回滚步骤。
